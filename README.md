# DUH Streak Tracker

A focused daily streak tracker built with Next.js, Prisma, Supabase, and web push notifications.

## Local setup

1. Install dependencies with `npm ci`.
2. Copy `.env.example` to `.env.local` and add the required values.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Checks

- `npm run typecheck`
- `npm run lint`
- `npm run build`
